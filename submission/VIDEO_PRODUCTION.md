# Offroof 2분 35초 제출 영상 제작표

기준 대본은 [`DEMO_SCRIPT.md`](./DEMO_SCRIPT.md)입니다. 최종 영상은 **2분 35초 이하·1920×1080 가로 화면**으로 만들고, 실제 공개 앱과 실제 네이티브 WebMCP 결과만 보여줍니다.

## 1. 녹화 시작 상태

- [ ] 최종 배포 URL을 열고 새로고침해 정상 동작을 확인한다. 최종 제출 영상에는 `localhost`를 사용하지 않는다.
- [ ] 화면 해상도 `1920×1080`, 브라우저 확대 `100%`, 한국어 화면으로 맞춘다.
- [ ] 북마크 바·알림·프로필·다른 탭·주소 자동완성 등 개인 정보가 보이지 않게 정리한다.
- [ ] **새 검토**를 눌러 이전 원문, 동의, 체크리스트, 작업 로그를 초기화하고 **제안 검토** 화면에서 시작한다.
- [ ] WebMCP 상태가 `6개 연결`인지 확인한다. 수동 모드라면 녹화를 시작하지 않는다.
- [ ] 네이티브 도구 목록에서 아래 6개가 실제로 발견되는지 확인한다.
  - `inspect_offer_signals`
  - `get_case_summary`
  - `build_verification_plan`
  - `update_verification_step`
  - `get_official_resources`
  - `get_action_receipts`
- [ ] 마이크 테스트를 하고 목소리가 찢어지거나 너무 작지 않은지 10초 시험 녹화로 확인한다.

## 2. 클립별 촬영표

각 도구 호출에는 **현재 실행에서 반환된 최신 `caseId`, `caseVersion`, `stepId`**만 사용합니다. 미리 적어 둔 예전 값이나 고정된 가짜 결과를 사용하지 않습니다.

| 최종 시간 | 화면에서 할 일 | 편집 기준 |
| --- | --- | --- |
| `0:00–0:12` | **안전한 예시 불러오기** → 개인정보 확인 체크 → 네이티브 `inspect_offer_signals({})` 호출 → 신호 6개가 표시된 사례 기록으로 이동 | 클릭과 실제 호출은 남기고 로딩 대기만 자른다. 첫 12초 안에 실제 결과를 보여준다. |
| `0:12–0:30` | 첫 신호 카드의 원문 근거, 관찰, 제한된 추론, 한계를 천천히 보여준다 | 한 카드가 읽힐 정도로 멈춘다. 사기 점수나 판정처럼 설명하지 않는다. |
| `0:30–0:50` | 네이티브 WebMCP 목록에서 **6개 도구 전체**를 한 화면에 보여주고 `get_case_summary({})`를 실제 호출한다 | 목록과 구조화된 결과가 최소 2초씩 또렷하게 보이게 한다. 모의 패널·Inspector 전용 가짜 결과로 대체하지 않는다. |
| `0:50–1:10` | 에이전트 변경 동의가 꺼진 상태에서 최신 사례 ID/버전으로 `build_verification_plan` 호출 → 차단 결과와 차단 영수증 표시 | 실패 화면을 숨기지 않는다. 동의 전 변경이 차단된다는 점이 읽혀야 한다. |
| `1:10–1:36` | 앱에서 **에이전트 변경 허용** 체크 → 최신 값으로 `build_verification_plan` 재호출 → 확인 계획이 생긴 화면 표시 | 체크 동작과 성공 결과를 모두 남긴다. 호출 사이의 입력·대기는 짧게 컷한다. |
| `1:36–1:55` | 방금 반환된 최신 `stepId`와 버전으로 `update_verification_step` 호출 → 한 항목 완료와 **직전 변경 되돌리기** 버튼 표시 | 체크리스트가 실제로 바뀌는 순간을 자르지 않는다. 되돌리기는 눌러도 되지만 결과가 혼란스러우면 버튼만 보여준다. |
| `1:55–2:12` | `get_action_receipts({})` 실제 호출 → 읽기, 차단된 변경, 성공한 변경 행을 작업 로그에서 보여준다 | 원문이나 도구 인수가 영수증에 저장되지 않는다는 화면 근거를 보여준다. |
| `2:12–2:25` | `get_official_resources({})` 실제 호출 → 공식 자료 카드 표시 → 한/영 버튼을 바꿨다가 같은 사례가 유지되는 모습 표시 | 외부 링크는 열지 않는다. 자동 신고·결제·메시지 기능처럼 보이게 편집하지 않는다. |
| `2:25–2:35` | **소개** 화면의 Offroof 이름과 “제안은 말로, 확인은 근거로.” 문구로 마무리 | 마지막 프레임을 2초 이상 유지하고 갑자기 끊지 않는다. |

## 3. 컷 편집 체크

- [ ] 최종 길이는 `2:35` 이하이며 첫 결과가 12초 안에 나온다.
- [ ] 로딩, 값 복사, 도구 선택, 창 배치 같은 준비 시간만 잘라낸다.
- [ ] 실제 클릭 → 실제 결과의 순서는 바꾸지 않는다. 다른 실행의 결과를 이어 붙여 한 번의 호출처럼 꾸미지 않는다.
- [ ] 과한 줌, 번쩍이는 전환, 배경 음악보다 화면 글자와 영어 설명의 명료성을 우선한다.
- [ ] WebMCP 도구명, 차단 결과, 성공 결과, 작업 로그는 각각 최소 2초 동안 읽을 수 있다.
- [ ] 최종 출력은 `1920×1080`, 16:9, MP4(H.264 권장), 30fps 이상으로 확인한다.

## 4. 오디오·영어 자막

- [ ] [`DEMO_SCRIPT.md`](./DEMO_SCRIPT.md)의 영어 내레이션을 그대로 사용하거나 같은 의미의 정확한 영어 자막을 넣는다.
- [ ] 내레이션이 배경 음악보다 명확하고, 좌우 한쪽에서만 들리지 않는지 이어폰으로 확인한다.
- [ ] `OFFROOF_EN.srt`를 사용한다면 파일이 실제로 존재하고 영상과 동기화되는지 확인한다.
- [ ] 자막은 화면 아래 안전 영역 안에 두고 한 번에 두 줄을 넘기지 않는다.
- [ ] `WebMCP`, `Offroof`, 도구명과 숫자 `6`의 철자를 마지막으로 교정한다.

## 5. 개인정보·진실성 최종 확인

- [ ] 앱 내장 가상 예시만 사용하며 실제 이름, 이메일, 전화번호, 계정, 제안서, 비밀번호, API 키가 한 프레임도 나오지 않는다.
- [ ] 브라우저 프로필 사진, 알림, 작업표시줄 미리보기, 다른 서비스 탭을 프레임 단위로 확인한다.
- [ ] “사기 판정”, “악성 파일 검사”, “이메일 자동 수집”, “자동 신고”처럼 구현되지 않은 기능을 말하거나 자막에 넣지 않는다.
- [ ] 네이티브 도구 6개 발견 화면과 6개 도구의 실제 호출 장면이 모두 포함되어 있다.
- [ ] 수동 버튼 동작을 WebMCP 호출이라고 설명하지 않는다.

## 6. 업로드 후 비로그인 검증

- [ ] YouTube 공개 상태로 업로드하고 처리 완료 후 `1080p` 재생이 가능한지 확인한다.
- [ ] 로그아웃 또는 시크릿 창에서 영상 URL을 열어 로그인 없이 처음부터 끝까지 재생한다.
- [ ] 같은 비로그인 창에서 공개 앱 URL과 GitHub 저장소 URL도 열리는지 확인한다.
- [ ] 영어 자막 선택, 음량, 화질, 제목, 설명, 썸네일, 영상 길이를 확인한다.
- [ ] Devpost에 붙여 넣은 세 URL(앱·저장소·YouTube)을 미리보기 화면에서 다시 누른다.

문제가 하나라도 있으면 해당 항목을 고친 뒤 **비로그인 검증부터 다시** 진행합니다. 제출 완료 화면을 저장하기 전까지 녹화 파일 원본과 최종 MP4를 보관합니다.
